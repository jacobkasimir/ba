# Python API reference

The API pages below are generated from selected Python module docstrings with
pdoc. The application and gateway both contain a package named `app`; their
references are generated in separate import environments and are kept under
separate paths.

- [Application API](api/application/index.html)
- [Gateway API](api/gateway/index.html)

The reference excludes service entry points that load runtime configuration,
secrets, or database settings. It covers the public request models, assistant
orchestration and clients, MCP client, query policy, and gateway schemas.
